      如何使用这份配置
      

        生成产物是一份完整的 sing-box 配置 JSON。
        
    
          
  • GUI 客户端：把下载的 singbox-config.json 作为配置文件导入。
    • 
          
  • 命令行：保存为 config.json 后运行 sing-box run -c config.json。
    • 
          
  • 配置按客户端形态生成：开 TUN 接管并带 DNS 骨架，需给 sing-box 相应的系统权限（与 Tower 生成的一致）。
    • 
          
  • ACL4SSR 会生成 🚀 节点选择 / ♻️ 自动选择 / 各地区组 等策略组，可在带 clash_api 的客户端面板里手动切换。
    • 
          
  • 国内 IP 直连依赖 sing-box 启动时拉取 geoip-cn 规则集；不联网的部署可改用「不使用（默认分域模板）」。
    • 
        

        订阅与凭据保存在服务端数据文件（singbox-web.data.json）里，
        解析与生成也都在你自己的服务或本机完成。该文件等同于一份凭据清单，不要放进代码仓库或共享目录。
        


        订阅地址本身是一条能力链接：任何拿到它的人都能取到你的全部节点。
        apiToken 只保护 /api/*，
        并不保护 /sub/<token>。
        需要对外提供时，请在前面套一层 HTTPS 反向代理（本服务自身只监听明文 HTTP），把「对外地址」填成那层代理的地址；
        想收回已经发出去的链接，用上面的「轮换密钥」，旧地址立刻失效。
