      如何使用这份配置
      

        生成产物是一份完整的 sing-box 配置 JSON。
        
    
          
  • GUI 客户端：把下载的 singbox-config.json 作为配置文件导入。
    • 
          
  • 命令行：保存为 config.json 后运行 sing-box run -c config.json。
    • 
          
  • “全功能客户端”场景默认开 TUN 接管，需给 sing-box 相应的系统权限；“桌面本地代理”则把代理指向 127.0.0.1:1080。
    • 
        

        订阅文本与凭据只存在本浏览器 localStorage，解析与生成都在你自己的服务/本机完成。
